# 무인기 비행·통신·안전 기초

## 데이터 해석

위치는 측정값과 추정값을 구분하고 수평·수직 기준, 좌표계, 정확도, 관측 시각을 함께 다룬다. 자세는 roll/pitch/yaw의 축과 부호, frame을 계약한다. 배터리 잔량은 임무 가능성과 같지 않으므로 소비율, 바람·경로 가정, 복귀 여유를 포함한다.

## 통신 단절

서버 재접속 기능만으로 안전을 보장할 수 없다. 임무 시작 전에 hold, abort, return과 같은 기체 측 정책과 적용 조건을 정한다. 재접속 시 단절 중 상태·실행 이력·현재 세션을 먼저 대조하고 만료 명령을 폐기한다.

## 안전 분석

FMEA에는 원인, 영향, 탐지 방법, 기존 통제, 추가 완화, 검증 시험을 기록한다. 단일 장애뿐 아니라 링크 저하+배터리 부족, 위치 품질 저하+금지구역 접근 같은 복합 조건을 시험한다.

실기체 단계에서는 운용 지역의 최신 법규, 승인, 제조사 제한, 비상 절차를 해당 기관과 공식 자료로 다시 확인해야 한다.
