# SentinelGrid 종합 기획서

## 1. 프로젝트 정의

SentinelGrid는 지정된 도시 구역과 공장 부지를 가상 무인 순찰체가 반복 순찰하고, 운영자가 지도에서 임무 진행·순찰체 상태·통신 품질·안전 사건을 확인하는 고신뢰 상황인지 플랫폼이다.

SentinelGrid는 민간 도시 운영과 산업현장의 반복 순찰, 관측 품질, 미순찰 구간, 사건 대응을 핵심 문제로 삼는 신규 시스템이다. 초기 MVP는 가상 UAV를 사용하지만 도메인 모델은 향후 지상 순찰 로봇과 고정 센서를 수용할 수 있도록 `PatrolUnit` 중심으로 설계한다.

V01은 Operational Picture, Patrol Mission, Telemetry Reliability, Command & Control, Incident Management, Replay & Audit 순서의 수직 슬라이스로 개발한다. 각 슬라이스에서 React+TypeScript 화면과 상태, 도메인 규칙, API·이벤트 계약, Go·Rust·Python 구현과 통합시험을 함께 완료한다.

단순한 드론 위치 시각화가 아니라 다음 문제를 다룬다.

- 순찰 경로와 체크포인트를 실제로 통과했는가
- 통신 단절 중 미확인 구간은 어디인가
- 오래되거나 부분 갱신된 정보를 현재 상태로 오인하지 않는가
- 한 기체가 이탈했을 때 미수행 구간과 대체 기체를 찾을 수 있는가
- 명령이 전송·수락·실행·효과 확인 중 어디까지 진행됐는가
- 경보가 많아질 때 하나의 Incident로 묶어 우선순위를 정할 수 있는가
- 사후에 당시 데이터·정책·배포·운영자 판단을 재구성할 수 있는가

## 2. 적용 시나리오

### 도시 순찰

- 공원·하천변·도로 주변의 정기 순찰
- 재난·침수·연기·통행 장애 모의 확인
- 행사·공사 구역의 지정 경로 확인
- 통신 음영 구간과 미확인 구간 표시

### 공장 부지 순찰

- 외곽 경계·출입구·창고·설비 구역 순찰
- 연기·열 이상·시설물 파손 후보 이벤트 확인
- 위험 구역 진입 제한과 Geofence
- 야간·통신 열화·기체 이탈 시 임무 재배정

## 3. 사용자

| 사용자 | 책임 |
|---|---|
| 관제 운영자 | 실시간 상태 확인, 저위험 명령, 사건 확인 |
| 임무 관리자 | 순찰 구역·경로·주기·체크포인트 설계 |
| 승인자 | 고위험 명령과 정책 변경 승인 |
| 안전 관리자 | Geofence·Failsafe·개인정보 보존 정책 관리 |
| 분석 담당자 | Replay, 사건 분석, 모델 평가 |

## 4. 핵심 기능

1. 순찰 구역·경로·체크포인트·운용 시간대 관리
2. 다중 가상 기체 임무 배정과 진행률 계산
3. 위치·자세·배터리·통신·탑재체 Telemetry 수집
4. 필드별 Freshness와 `KNOWN/STALE/PARTIAL/UNKNOWN`
5. 경로 이탈·체크포인트 미통과·통신 단절 경보
6. 미확인 구간과 순찰 Coverage 표시
7. Hold·Resume·Return·Abort 명령 승인·결과 추적
8. 단절 후 Snapshot·Sequence·미종결 명령 Reconciliation
9. 반복 경보를 Incident로 묶고 조치·해제 이력 관리
10. 사건 Timeline·Telemetry·배포 버전 Replay
11. Python 이상 탐지와 근거 기반 RAG·LLM 설명
12. MLOps·DevSecOps·배포 Rollback 증거 관리

## 6. 성공 기준

- 10대×1Hz 순찰을 20분 이상 안정 처리
- 수집→관제 화면 반영 로컬 p95 500ms 이하
- 오래된 Event의 최신 상태 후퇴 0건
- 중복 Command 효과 실행 0건
- 순찰 Coverage와 미확인 구간을 구분해 표시
- 정의된 단절 Scenario에서 Reconciliation 100% 성공
- AI 중단 시 규칙 기반 관제 기능 유지
- 얼굴 인식·개인 식별 없이 사건 후보를 처리
- 코드·Schema·정책·모델·운용 Session 역추적 가능

## 7. 제외 범위

실제 비행제어, SLAM, 실시간 고해상도 영상 스트리밍, 얼굴 인식, 개인 식별·지속 추적, 무장·표적화·공격 자동화, 완전 자율 대응은 MVP에서 제외한다.
