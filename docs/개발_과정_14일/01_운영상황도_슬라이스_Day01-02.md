# Day 01–02 — Operational Picture 슬라이스

## 프론트엔드

- React App Shell과 MapLibre 지도를 만든다.
- Site Profile, 순찰구역, 경로, 순찰체 marker를 Mock으로 표현한다.
- FRESH, STALE, MISSING과 loading·empty·error 상태를 만든다.

## 도메인·백엔드

- `PatrolUnitSnapshot`과 `ObservedValue` 규칙을 정의한다.
- Go에 Operational Picture 조회 API를 구현한다.
- PostgreSQL에 최소 순찰체·관측 projection을 저장한다.
- React Mock을 실제 API로 교체한다.

## 완료 게이트

화면에서 최신 상태와 오래된 관측을 구분하고, 계약·도메인·UI 시험이 함께 통과한다.
