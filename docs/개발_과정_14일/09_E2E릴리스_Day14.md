# Day 14 — E2E 릴리스

## 작업

- 도시 정상 순찰과 공장 복합 장애 시나리오를 수행한다.
- 링크 단절, 역순 이벤트, 순찰체 이탈, 명령 ACK 유실, AI fallback을 검증한다.
- React 화면, 도메인 상태, 이벤트, DB 감사 기록과 trace를 대조한다.
- Compose 배포·백업 복원·이전 이미지 복구를 리허설한다.
- 요구사항 추적표와 데모 영상을 준비한다.

## 완료 게이트

각 기능이 프론트엔드와 백엔드를 함께 포함한 수직 슬라이스로 동작하고, 성공뿐 아니라 실패·복구·판단 불가 상태까지 설명할 수 있다.
