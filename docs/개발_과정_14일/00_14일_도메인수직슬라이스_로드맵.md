# 14일 도메인 수직 슬라이스 로드맵

## 목표

React와 백엔드를 기능별로 번갈아 구현해 14일 동안 여섯 개의 동작 가능한 수직 슬라이스를 만든다.

| 일자 | 도메인 슬라이스 | 프론트엔드 ↔ 백엔드 결과 |
|---|---|---|
| 1–2 | Operational Picture | React 지도 ↔ Go snapshot·PostgreSQL |
| 3–4 | Patrol Mission | 임무 UI ↔ Go Mission·PostGIS |
| 5–6 | Telemetry Reliability | 신선도 UI ↔ Python·Rust·Go projection |
| 7–8 | Command & Control | 명령 UI ↔ Go Lease·Command·Rust result |
| 9–10 | Incident Management | 사건 UI ↔ Go Incident·Python 분석 |
| 11 | Replay & Audit | 재현 UI ↔ event·audit query |
| 12 | 통합 품질 | 인증·권한·관측성·contract regression |
| 13 | Compose 운영환경 | profile·health·network·volume·보안검사 |
| 14 | E2E 릴리스 | 도시·공장 시나리오와 장애 복구 증거 |

각 단계는 화면, 도메인 규칙, 실제 API, 대표 장애시험이 모두 완료돼야 종료한다.
