# Day 07–08 — Command & Control 슬라이스

## 프론트엔드

- 명령 요청·승인·전송·수락·실행·결과 확인을 분리해 표시한다.
- 통제권 충돌, 만료, ACK 유실과 취소 경합 상태를 만든다.

## 도메인·백엔드

- Go에 ControlLease와 Command aggregate를 구현한다.
- 권한, 정책 버전, 만료, idempotency를 검증한다.
- Rust에 command result 우선 전달 경로를 추가한다.
- 관측 상태와 명령 결과를 대조해 실제 완료 여부를 판단한다.

## 완료 게이트

동시 명령과 ACK 유실에도 중복 효과가 발생하지 않고, 근거가 없으면 UI가 결과를 `UNKNOWN`으로 유지한다.
