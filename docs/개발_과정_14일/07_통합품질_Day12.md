# Day 12 — 통합 품질

## 작업

- 역할별 조회·승인·통제 권한을 E2E로 검증한다.
- OpenAPI·이벤트 schema와 React runtime validation을 회귀시험한다.
- trace ID를 React 요청, Go 처리, Rust 수집, Python 분석에 연결한다.
- queue lag, freshness, command latency, incident 처리시간 지표를 만든다.
- 오류 응답과 UI 복구 동작을 정리한다.

## 완료 게이트

여섯 수직 슬라이스가 인증·계약·관측성 기준을 공통으로 충족하고 기능 간 회귀가 없다.
