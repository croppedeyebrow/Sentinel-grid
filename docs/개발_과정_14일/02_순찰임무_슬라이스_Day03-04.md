# Day 03–04 — Patrol Mission 슬라이스

## 프론트엔드

- 구역, 경로, 체크포인트와 순찰체 배정 UI를 만든다.
- 임무 상태와 coverage·미순찰 구간을 표시한다.

## 도메인·백엔드

- PatrolArea, Route, Mission, Assignment aggregate를 정의한다.
- Go에 임무 생성·승인·시작·중단·완료 전이를 구현한다.
- PostGIS에 구역·경로를 저장하고 포함·교차 질의를 만든다.
- React에서 실제 임무 API와 연결한다.

## 완료 게이트

도시 또는 공장 구역에서 임무를 만들고 실행 상태와 미순찰 구간을 실제 데이터로 확인한다.
