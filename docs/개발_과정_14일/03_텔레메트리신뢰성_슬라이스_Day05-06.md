# Day 05–06 — Telemetry Reliability 슬라이스

## 프론트엔드

- 센서별 freshness, 부분 갱신, 링크 단절과 재접속 상태를 구현한다.
- 위치는 오래됐지만 배터리는 최신인 상태를 표현한다.

## 백엔드·통신

- Python Simulator가 정상·지연·중복·역순·단절 이벤트를 생성한다.
- Rust Gateway가 schema, session, sequence와 크기를 검증한다.
- Redis Streams와 Go projection을 연결한다.
- React WebSocket에서 snapshot+delta와 sequence gap을 처리한다.

## 완료 게이트

동일 장애 시나리오에서 UI, Go projection, 원본 이벤트가 합의된 신선도 결과를 만든다.
