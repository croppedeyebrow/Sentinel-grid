# CS·동시성·분산 신뢰성

## 반드시 이해할 주제

- at-least-once 전달과 멱등성
- happens-before, race condition, optimistic concurrency
- event time과 processing time, clock skew
- backpressure, bounded queue, load shedding
- state machine과 불변조건
- transactional outbox와 projection replay
- timeout, retry, circuit breaker가 만드는 중복
- partial failure와 `UNKNOWN` 상태

## 학습 방법

각 개념을 SentinelGrid 장애 시나리오로 증명한다. 예를 들어 ACK 유실은 단순 timeout 문제가 아니라 `명령이 실행됐지만 결과만 잃은 상태`다. 재전송 전에 idempotency와 관측 상태 대조가 필요하다. 개념마다 실패 fixture, 기대 상태, 복구 절차를 테스트로 남긴다.
