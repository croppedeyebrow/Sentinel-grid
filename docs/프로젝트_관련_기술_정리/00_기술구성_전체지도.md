# 기술 구성 전체 지도

| 영역 | 기술 | 먼저 학습할 내용 | 프로젝트 적용 |
|---|---|---|---|
| 임무 백엔드 | Go | context, goroutine, interface, transaction | mission·command SoR |
| 수집·통신 | Rust | ownership, async Tokio, bounded channel | telemetry gateway |
| 분석·시뮬레이션 | Python | asyncio, NumPy/Pandas, ML 평가 | simulator·anomaly·RAG |
| 관제 UI | React+TypeScript | query/cache, WebSocket, map | 실시간 운영 화면 |
| 공간 DB | PostgreSQL+PostGIS | transaction, index, geometry | 구역·경로·coverage |
| 이벤트 | Redis Streams | consumer group, pending, replay | 비동기 전달 |
| 운영 | Docker Compose·OTel | 컨테이너 배포, 보안, trace·metric·log | DevSecOps·관측성 |

학습은 문법 강의 순서가 아니라 `이벤트 수집 → 상태 계산 → 임무 판단 → 화면 표시 → 장애 복구`의 수직 흐름을 따라 진행한다.
