# AI·MLOps·RAG·LLM

## 학습 순서

1. 문제·라벨·평가 단위 정의
2. 규칙·통계 baseline
3. 시간·기체 단위 데이터 분할
4. 특징·모델·임계값 버전 관리
5. Shadow·canary·rollback
6. retrieval·reranking·citation 평가
7. 자체 호스팅 추론의 batching·quantization·자원 측정

LLM은 사건 설명과 보고서 초안을 만들며 사실·가설을 분리한다. 생성 결과에는 검색 근거와 문서 버전을 연결한다. 프롬프트 공격과 권한 없는 문서 검색을 막기 위해 검색 전후에 접근 통제를 적용한다.

모델 선택은 이름보다 재현 가능한 평가셋, 지연, 메모리, 라이선스, 오프라인 운영 가능성으로 결정한다.
